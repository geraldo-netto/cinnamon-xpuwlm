# Presentation review

Presentation review reuses the selected-file media worker for PPTX, ODP, and
PDF. Its visible text and visual descriptions are preserved in slide/page order.
Every observation, note, accessibility description, and likely question is
attached to that exact position and cites a non-empty span of the source text or
visual description. Review output is immutable as evidence but explicitly
marked editable for the UI; it contains no write or export operation.
