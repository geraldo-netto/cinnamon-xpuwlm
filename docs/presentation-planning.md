# Presentation planning and export

Planning consumes a validated presentation review and produces one editable
deck intermediate. Each planned slide preserves one or more review-evidence
citations; asset references must belong to the explicitly selected asset set.

Export supports PPTX and ODP only. The language stage never receives a writer.
It can create an `export-presentation` request for the host-owned deterministic
action port, which previews effects, refuses overwrite, records audit evidence,
and consumes a fresh explicit confirmation before its writer is called.
