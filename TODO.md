| XTPU-0078 | open | medium | s | — | Staged input buffers orphan whenever a job does not reach its terminal state under this applet instance. The submitter removes the buffer on refusal and the manager removes it at the terminal poll, but `_cancelPolling` (lib/manager.js) drops `_polling.stagedPath` without discarding — so disposal, an applet reload, or a Cinnamon crash mid-job leaves the `.f32` in `.tpuwm-staged` forever, and nothing sweeps that directory at startup. Each orphan is ~600 KB of a user-owned directory; a session of interrupted jobs accumulates them silently. Fix both ends: discard on `_cancelPolling` when polling is abandoned (the runtime has either read the file by then or never will — dispatch re-reads at execution, so removal only races a job that is already failing), and sweep stale files from the staging directory when the applet starts. |
